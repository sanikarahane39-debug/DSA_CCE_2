# Stationery Item Management Using Singly Linked List

1) Problem Statement
To develop a C++ program to manage stationery items using a Singly Linked List.

2)Objectives
- Insert and delete stationery items.
- Search and display item details.
- Calculate the total bill.
- Update item quantity.
- Count total types of items.
- Display low-stock alerts.

3)Introduction
A Singly Linked List is a linear data structure in which each node contains data and a pointer to the next node.

This project manages stationery items such as pens, pencils, and notebooks. It stores item names, quantities, and prices.

4) Algorithm
1. Start the program.
2. Initialize `head = NULL`.
3. Display the menu.
4. Enter the user's choice.
5. Perform the selected operation.
6. Repeat until the user selects Exit.
7. Stop the program.


5) Operations
1. Insert Item
2. Delete Item
3. Search Item
4. Display Items
5. Calculate Total Bill
6. Update Quantity
7. Count Items
8. Exit

6) Technologies Used
- Programming Language: C++
- Data Structure: Singly Linked List
- Concepts: Pointers, Structures, Dynamic Memory Allocation

7)Result
The Stationery Item Management System was implemented successfully using a Singly Linked List in C++.

8)Conclusion
This project helps us understand linked list operations and their practical application in stationery item management.
